# ArtForge AI MCP — Customer Trial

هذه الحزمة تشغّل نسخة مستقلة من محرّك ArtForge، مع تخطيط التصاميم، والرسم بالعربية، وإضافة الأشكال والنصوص إلى اللوحة، والمعاينة والتصدير بصيغ PNG وJPEG وWebP. مسار الاتصال `/mcp` يستخدم HTTP وJSON-RPC. يدعم التهيئة والاكتشاف حسب عميل MCP المستخدم.

تضم النسخة لوحة ألوان وإعداد تخطيط أُعدّا للتجربة، وقد تختلف النتيجة بصريًا عن نسخة المالك التي تستخدم مكتبته الخاصة. تضم الحزمة تراخيص الخطوط المرفقة. وضع التجربة يقصر العمليات على الرسم الأساسي والمعاينة والتصدير النقطي. استيراد ملفات المضيف، ومزوّدو التوليد الخارجيون، وتصدير PDF وPSD وSVG وحزم المشاريع خارج نطاق التجربة.

## اختبار محلي

```sh
npm ci --prefix drawing-tool --omit=dev --ignore-scripts
node server.js
```

العنوان المحلي `http://127.0.0.1:4273/mcp`. المعاينة محليًا تعمل دون رمز. مجلدات التصاميم والتصدير تُنشأ عند أول تشغيل. استخدم مجلدًا مستقلًا لهذه النسخة.

## تشغيل تجربة للعميل

أنشئ حاوية مستقلة لكل عميل. يولّد مشغّل الاستضافة رمزًا جديدًا عشوائيًا للتجربة، بطول 32 حرفًا على الأقل من أحرف Base64url، ويقدمه للحاوية كملف أسرار مقروء لمستخدم `node` في المسار `/run/secrets/artforge_demo_token`. يبدأ الخادم على واجهة الشبكة فقط مع رمز صالح. يدعم عميل MCP المتوافق إرسال `Authorization: Bearer <trial-token>`.

```sh
docker build -t artforge-customer-trial .
docker run --rm --name artforge-trial --cpus 2 --memory 2g --pids-limit 128 --cap-drop ALL --security-opt no-new-privileges -p 127.0.0.1:4273:4273 --mount type=bind,source=/path/to/fresh-trial-token,target=/run/secrets/artforge_demo_token,readonly artforge-customer-trial
```

قدّم `/mcp` عبر وكيل HTTPS يمرّر رأس `Authorization`. أبقِ منفذ محرّك الرسم داخليًا. خصّص تخزين الحاوية للعميل الحالي فقط، وأنهِ الحاوية عند انتهاء التجربة. تعالج كل نسخة طلبًا في كل مرة وتحدّ أبعاد التخطيط بـ 1600 بكسل لكل ضلع. اختبر الاكتشاف والرسم والتصدير من عميل MCP الذي سيستخدمه العميل. إذا كان عميل الربط يتطلب OAuth، فجهّز تدفق OAuth متوافقًا قبل إتاحة الرابط.

## حدود التحقق

اختُبر محليًا مسار HTTP بمحرّك الرسم الأصلي. صورة Docker واتصال عميل خارجي عبر HTTPS يحتاجان تحققًا في بيئة النشر. يتطلب تشغيل هذه الحزمة على Cloudflare استخدام Containers ضمن خطة Workers Paid، أو تشغيل الحاوية على مضيف آخر وتقديمها عبر HTTPS.
