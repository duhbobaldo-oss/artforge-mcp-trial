# 7) الحفظ والفتح والتصدير

## حفظ التصميم (ملف قابل لإعادة الفتح)

```json
{ "op": "document.save", "params": { "documentId": "doc_x" } }
```

- بدون `path` يُحفظ في `drawing-tool/data/documents/<documentId>.artforge.json`.
- مع `path` يجب أن ينتهي بـ`.json` أو `.artforge.json`.
- المحتوى: كل شيء (اللوحة، الخلفية، الطبقات، العناصر، التحريك، البيانات الوصفية) — لا تُفقد أي معلومة قابلة للتعديل.
- النتيجة: `path`، `bytes`، `stats`، `revision`.

المستندات المحفوظة تُحمَّل تلقائيًا في المخزن عند تشغيل الخادم من جديد.

## فتح تصميم

| الحالة | العملية |
|---|---|
| ملف على القرص (مسار يعرفه الخادم) | `document.open { path, replace? }` |
| كائن تصميم جاهز (رفع من الواجهة أو من MCP) | `document.import { document, replace? }` |

- التحقق: يجب أن يكون `schema = "artforge.document"` و`version = 1`، وإلا `INVALID_DESIGN_FILE` / `UNSUPPORTED_VERSION`.
- إذا كان المعرّف موجودًا وبدون `replace:true` يُنشأ نسخة بمعرّف جديد واسم «(copy)».
- عند الفتح يُعاد التحقق من كل الحقول (نفس تحقق الإنشاء) فلا يمكن إدخال ملف تالف.

## تصدير صورة

```json
{ "op": "export.image",
  "params": { "documentId": "doc_x", "format": "png", "scale": 2, "outPath": "outputs/poster@2x.png" } }
```

| المدخل | القيم | ملاحظات |
|---|---|---|
| `format` | `png` / `jpeg` / `webp` | `jpg` مقبول كمرادف لـ`jpeg` |
| `scale` | > 0 وحتى 4 | 2 يعني ضعف الأبعاد |
| `quality` | > 0 وحتى 1 | لـjpeg/webp فقط (افتراضي 0.92) |
| `time` | ms | زمن التحريك المطلوب تصويره |
| `static` | `true` | يتجاهل التحريك ويصدّر الحالة الأساسية |
| `outPath` | مسار | نسبي يُحلّ مقابل جذر المشروع؛ بدون مسار يُكتب في `data/exports/` |

حد الحماية: أبعاد الصورة الناتجة يجب أن تبقى ≤ 16384 بكسل في كل اتجاه، وإلا `EXPORT_TOO_LARGE`.
JPEG لا يدعم الشفافية، لذلك تُملأ الخلفية بالأبيض تلقائيًا عند تصدير JPEG إذا كانت خلفية التصميم شفافة.

النتيجة تحتوي `sha256` للملف — يمكن استخدامه كإثبات أن الملف تغيّر أو تطابق.

## تصدير إطارات التحريك

```json
{ "op": "export.frames", "params": { "documentId": "doc_x", "fps": 12 } }
```

- يتطلب `animation.enabled = true` وإلا `ANIMATION_DISABLED`.
- عدد الإطارات = `round(duration/1000 × fps)`، وأسماء الملفات `frame_0000.png`، `frame_0001.png`…
- النتيجة تحتوي مسار كل إطار وحجمه و`sha256` الخاص به.

## معاينة بدون كتابة ملف

`export.preview { documentId, maxWidth, time?, static? }` يعيد `dataUrl` (PNG base64) — مناسب لعرض النتيجة في واجهة أخرى أو داخل ChatGPT.

## ما الذي «يُحفظ» فعليًا؟

- الصور المضافة تُخزَّن كأصول في `data/assets/` مع ملف `index.json` (بصمة SHA-256 لكل أصل)، والمستند يشير إليها بـ`assetId`.
- إذا نُقل ملف التصميم إلى جهاز آخر بدون مجلد الأصول، تُرسم العناصر النصية والأشكال كما هي، وتُتجاهل الصور الناقصة مع تحذير في `warnings` (لا يفشل التصدير).

## الحذف

`document.delete { documentId }` يحذف المستند من الذاكرة ومن القرص. لا توجد سلة محذوفات (غير مدعوم — انظر `11-limits.md`).
