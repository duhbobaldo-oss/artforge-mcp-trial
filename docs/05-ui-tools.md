# 5) أدوات الواجهة وطريقة عملها

الواجهة عربية بالكامل (`dir="rtl"`) وتعمل في المتصفح على `http://127.0.0.1:4173/`.
كل فعل في الواجهة يُنفَّذ عبر نفس الـHTTP API؛ لذلك يمكن تنفيذ أي شيء برمجيًا بدل الماوس، وكل تغيير برمجي يظهر في الواجهة تلقائيًا.

## شريط الأعلى

| الزر | الوظيفة | ما يستدعيه برمجيًا |
|---|---|---|
| جديد | نافذة (اسم/عرض/ارتفاع) ثم إنشاء لوحة | `document.create` |
| فتح | اختيار ملف `.artforge.json` من الجهاز وفتحه | `document.import` |
| حفظ | حفظ التصميم في مجلد المستندات | `document.save` |
| تصدير PNG | تصدير صورة PNG بالحجم الأصلي (لقطة ساكنة) | `export.image {format:'png', static:true}` |
| معاينة المحرّك | عرض صورة مولّدة من محرّك Node/Skia نفسه المستخدم في التصدير | `GET /api/documents/:id/preview.png` |
| حقل اسم التصميم | إعادة تسمية المستند عند التغيير | `document.update` |

## شريط الأدوات (يمين الشاشة في RTL)

| الأداة | الرمز | السلوك |
|---|---|---|
| تحديد/تحريك | ➤ | نقرة تختار العنصر (مع إظهار إطار التحديد والمقابض)، والسحب ينقل العنصر ويُثبّت الموضع عبر `object.update` |
| مستطيل | ▭ | سحب لرسم مستطيل بحواف مستديرة 16px ولون التعبئة من لوحة الخصائص |
| بيضاوي | ◯ | سحب لرسم بيضاوي/دائرة |
| خط | ╱ | سحب لرسم خط بسماكة 4px |
| رسم حر | ✎ | سحب لرسم مسار حر (يُرسَل كـ`draw.freehand`) |
| نص | T | نقرة لإنشاء نص بالخط والحجم والمحاذاة والنص المكتوب في لوحة «النص والخطوط» |
| صورة | 🖼 | نقرة ثم اختيار ملف صورة (PNG/JPG/WebP) لإضافتها في موضع النقر |
| تراجع / إعادة | ↶ ↷ | `history.undo` / `history.redo` |
| تكبير / تصغير | ＋ － | تغيير التكبير (0.05×–8×) |

أثناء السحب يظهر العنصر فورًا في مساحة الرسم كمعاينة محلية، وعند الإفلات يُرسل الطلب إلى الخادم فيصبح جزءًا من المستند (ويُسجّل في سجل العمليات).

## اللوحات

1. **الطبقات**: قائمة الطبقات (الأعلى أولًا) مع أيقونة الإظهار/الإخفاء، نسبة الشفافية، وزر الحذف. النقر يحدّد الطبقة التي ستستقبل العناصر الجديدة. زر «+ طبقة» يضيف طبقة باسم تسأل عنه.
2. **الخصائص**: تُعبّأ تلقائيًا عند تحديد عنصر: X, Y, العرض, الارتفاع, الدوران, الشفافية, التعبئة, الحدود, سماكة الحد. أزرار: تطبيق / نسخ / حذف.
3. **النص والخطوط**: مفتاح «عربية فقط» لتصفية الخطوط، قائمة الخطوط (★ = خط مضمّن)، الحجم، الوزن (400/700)، المحاذاة (يمين/وسط/يسار)، مربع النص، وزرّا «إضافة نص» و«تحديث المحدد».
4. **الألوان والتدرجات**: عيّنات ألوان جاهزة، ولونَا التدرج («من» و«إلى») والزاوية، وزرّا «تدرج على التحديد» و«تدرج الخلفية».
5. **الحركة**: المدة (ms)، الإطارات/ثانية، شريط الزمن، الخاصية، القيمة، «إضافة مفتاح»، «تصدير الإطارات»، وزر تشغيل/إيقاف للمعاينة الحيّة.
6. **سجل العمليات الحيّة**: يعرض كل عملية تُنفَّذ (من الواجهة أو برمجيًا) مع الوقت والزمن بالميلي ثانية ورقم الإصدار، ويتحدّث عبر SSE. زر «تفريغ» يمسح العرض فقط.

## شريط الحالة

يعرض: الأداة الحالية، إحداثيات المؤشر داخل مساحة الرسم، نسبة التكبير، ورقم إصدار المستند (يزيد مع كل تعديل — دليل على تحديث الحالة).

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `V` `R` `O` `L` `P` `T` `I` | تحديد/مستطيل/بيضاوي/خط/رسم حر/نص/صورة |
| `Ctrl+Z` / `Ctrl+Shift+Z` | تراجع / إعادة |
| `Ctrl+S` | حفظ |
| `Delete` | حذف العنصر المحدد |
| `Esc` | إلغاء التحديد |
| `+` / `-` | تكبير / تصغير |

## كيف تُشاهد العمليات البرمجية مباشرة

1. نفّذ أي عملية عبر `POST /api/op` أو عبر سطر الأوامر أو من ArtForge AI MCP.
2. الخادم يبثّ حدث `document-change` على `/api/events`.
3. الواجهة تعيد جلب المستند وترسمه فورًا (تأخير ~150ms) ويظهر السطر في سجل العمليات.

تحقّق فعلي: في `verification/ui-check.json` كان `liveViewUpdated: true` (تغيّرت بصمات البكسل في مساحة الرسم بعد تنفيذ عمليات من خارج الواجهة).

## أدوات فيجما في الواجهة (2026-11-08)

- القلم (P): انقر لنقطة حادة، اسحب لنقطة منحنية بمقبضين متناظرين (Alt يكسر التناظر)، انقر أول نقطة للإغلاق، Enter أو Esc للإنهاء، Backspace لحذف آخر نقطة.
- قلم الرصاص (Shift+P): الرسم الحر السابق.
- المضلع ⬠ والنجمة ★ والقوس ◔ والحلزون @: اسحب لرسمها، وShift لشكل منتظم. بعد الرسم تعود الأداة إلى التحديد والشكل محدد.
- لوحة «الشكل»: عدد الأضلاع أو الرؤوس، ونسبة العمق، واستدارة الزوايا، والبداية والمسح ونصف القطر الداخلي للقوس، واللفات والنمو والاتجاه للحلزون، ونصف قطر الزوايا (رقم أو 4 قيم) وتنعيم الزوايا للمستطيل، وتحويل الدائرة إلى قوس.
- سطل الطلاء للمتجهات ◧: انقر داخل منطقة مغلقة بالخطوط.
- منتقي الألوان: مربع التشبع والسطوع، وشريطا الصبغة والشفافية، وحقل HEX، والقطارة، وألوان المستند، والألوان الأخيرة، ومكتبة الألوان (74 لوحة). يفتح من مربع اللون بجانب «تعبئة» و«حدود» أو من زر «منتقي الألوان والمكتبة». السحب يعاين، وإفلات الماوس أو اختيار لون يطبّقه على التحديد (للخطوط والمسارات المفتوحة يُطبّق على الحد).
- محرر التدرج: خطي أو دائري أو مخروطي، وعدد غير محدود من النقاط: انقر الشريط لإضافة نقطة، واسحب النقطة لتحريكها، ونقرة مزدوجة أو زر «لون النقطة» لتغيير لونها، و«حذف النقطة».
- الشبكات المتجهة (Vector Networks) بالقلم: انقر نقطة موجودة لتتفرع منها خطوط جديدة. السلسلة البسيطة أو الحلقة تُحفظ مسارًا، وما يتفرع يُحفظ شبكة. مع تحديد شبكة، النقر على إحدى نقاطها بالقلم يكمل الشبكة نفسها.
- أداة تحرير النقاط (A) على الشبكة: اسحب أي نقطة (تتبعها مقابضها) أو أي مقبض.
- السطل داخل منطقة مغلقة من شبكة يلوّن تلك المنطقة داخل الشبكة نفسها، والنقر مرة أخرى بلون آخر يغيّره.
- مقابض القوس على اللوحة: عند تحديد دائرة أو قوس تظهر ثلاثة مقابض. مقبض البداية ومقبض النهاية يغيّران الزاوية والمسح، والمقبض الأزرق يغيّر نصف القطر الداخلي (حلقة). الدائرة تتحول إلى قوس عند أول سحب.
- مع أداة شكل مفعّلة، يُعد السحب على جسم شكل محدد تحريكًا فقط إذا وقع على تعبئته أو حده الفعلي، لا في أي مكان داخل مربعه المحيط.
