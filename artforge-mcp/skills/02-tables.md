# مهارة 02 — الجداول الاحترافية

## الغرض
جدول مقروء ومنسق من بيانات منظمة، دون توجيه كل خلية يدويًا.

## متى تُستخدم
كل طلب فيه جدول أو صفوف وأعمدة: أسعار، مشتريات، جداول زمنية، مقارنات، كشوف مصروفات.

## الأدوات
- `artforge_create_design` مع `table` (والنوع `table` يُكتشف تلقائيًا).
- أو داخل صفحة نصية/مسطرة: كتلة `{type:"table", columns, rows}` في `blocks`، أو `table` مع `ruled`.
- أو مباشرة على مستند موجود: `artforge_tool_op` بـ `op: "layout.table"`.

## شكل البيانات
```json
"table": {
  "columns": [
    { "title": "البند" },
    { "title": "الكمية", "format": "number" },
    { "title": "سعر الوحدة", "format": "currency", "currency": "ر.س", "decimals": 2 },
    { "title": "الخصم", "format": "percent" },
    { "title": "التاريخ", "format": "date" }
  ],
  "rows": [
    ["أجهزة حاسب", 12, 4250.5, 7.5, "2026-11-03"],
    { "kind": "section", "cells": [{ "text": "قسم فرعي", "colspan": 5 }] },
    { "kind": "subtotal", "cells": [{ "text": "المجموع الفرعي", "colspan": 2 }, 76240.97, "", ""] },
    { "kind": "total", "cells": [{ "text": "الإجمالي", "colspan": 2 }, 87677.12, "", ""] }
  ],
  "digits": "latin",
  "theme": { "headerFill": "#1f2a44", "headerText": "#ffffff" }
}
```
أو جدول نصي في `body` بصيغة `| أ | ب |`.

## ما يفعله المحرك تلقائيًا
رأس بلون مميز مع اختيار لون نص الرأس بأعلى تباين (WCAG)، وتلوين متبادل للصفوف، وتمييز `subtotal` و`total` و`section` بخط عريض وخلفية، ودمج الخلايا `colspan` دون رسم خطوط عبرها، وعرض أعمدة من القياس الحقيقي (أعمدة الأرقام والتواريخ لا تلتف، والنص الطويل يلتف ويكبر ارتفاع الصف). الأعمدة من اليمين في الجداول العربية، والنص العربي محاذى يمينًا، والأرقام محاذاة إلى طرف واحد ثابت. تُنسَّق العملات والنسب والتواريخ والأرقام الهندية عند الطلب. وإذا طال الجدول فإنه **يُقسَّم على صفحات مع تكرار الرأس** تلقائيًا. الألوان مشتقة من لوحة المرجع المختارة ما لم تمرّر `theme`.

## التعليمات الإلزامية
1. **لا تخترع بيانات.** بدون `table` أو جدول نصي يرد المحرك بـ `TABLE_DATA_REQUIRED`، فاطلب البيانات من المستخدم.
2. مرّر القيم أرقامًا خامًا (`4250.5`) مع `format`، لا نصوصًا منسقة مسبقًا، ليتمكن المحرك من التنسيق والمحاذاة.
3. الخلايا الفارغة `""` تبقى فارغة (لا تتحول إلى 0).
4. لتخصيص الألوان مرّر `theme` جزئيًا. المثال الكحلي/الأبيض/الرمادي هو أحد الأشكال فقط.

## التحقق
`verification.table.rowsExpected === rowsDrawn` عبر كل الصفحات، ولا تحذير `table needs at least …px` (الجدول أضيق من محتواه)، ولا `LOW_CONTRAST`.

## أخطاء شائعة
- رسم الجدول بـ `draw.rect` و`draw.text` لكل خلية: بطيء وبلا التفاف ولا تقسيم صفحات.
- أعمدة كثيرة في عرض صغير: سيحذّر المحرك. قلّل الأعمدة أو الخط، أو كبّر `width`.
