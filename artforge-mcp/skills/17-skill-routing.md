# مهارة 17 — موجّه المهارات Skill Router (ArtForge)

## الغرض
تحميل المهارات التي تحتاجها المهمة فقط، بالترتيب الصحيح، ضمن ميزانية سياق، دون تكرار أو تعارض.

## كيف يعمل
1. **الخصائص**: تُقاس من فهم الطلب (نوع التصميم، العناصر، العلاقات، الأعداد، المزاج، الإضاءة، النص العربي، الجدول، المرجع…)، ومن كلمات المستخدم نفسها لمهارات الأدوات (كلمات كاملة فقط): `photoEdit` (مؤثر، توهج، قناع، منحنيات، فلتر، وضع المزج…) ← `layers-and-effects`؛ `retouch` (رتوش، إزالة البقع، استنساخ، تشويه، تحديد…) ← `pixels-and-retouch`؛ `vectorTools` (شعار، أيقونة، مضلع، حلزون، أداة القلم، شبكة متجهة…) ← `drawing`؛ `editing` (عدّل، حرّك، محاذاة، توزيع… أو وجود `documentId`) ← `editing-workflow`؛ `exportFormat` (SVG، PDF، PSD، فوتوشوب، ICC، P3، للطباعة) ← `quality-delivery`.
2. **النقاط**: لكل مهارة محفزات بأوزان؛ النقاط مجموع أوزان المحفزات المطابقة. الحد الأدنى للاختيار 2.
3. **الاعتماديات**: مهارة تتطلب أخرى تجلبها (`scenespec-engine` تتطلب `scene-graph`).
4. **التعارض**: يُبقى الأعلى نقاطًا (`model-drawing` للـ sceneSpec اليدوي مقابل `scenespec-engine` الآلي).
5. **التكرار**: مهارة كل مواضيعها مغطاة بمهارات أعلى نقاطًا تُستبعد.
6. **الميزانية**: حد أقصى 3 مهارات فنون عامة، ثم يُحذف الأقل نقاطًا حتى تقل التكلفة عن الميزانية (افتراضيًا 9000 رمز، `budgetTokens`) والعدد عن 5.
7. **الترتيب** بالمرحلة: الإجراء ← الفهم ← البنية ← المراجع ← القرار الفني ← الرسم ← المراجعة.

`operating-procedure` تُختار دائمًا وأولًا. تكلفة كل مهارة تُحسب من طول ملفها الفعلي.

## الاستخدام
- في كل خطة: `direction.skills` (المختارة مع أسبابها، والمستبعدة مع سبب كل منها).
- قبل التخطيط: `artforge_tool_docs` مع `route: "<كلمات المستخدم>"` يعيد التوجيه نفسه دون تخطيط، ثم اقرأ المهارات المختارة بـ `guide`.

## التعليمات الإلزامية
1. لا تقرأ كل المهارات «احتياطًا»؛ اقرأ ما اختاره الموجّه.
2. إذا احتجت مهارة مستبعدة، اقرأها عمدًا واذكر السبب.

## الحدود
التوجيه قواعدي وقابل للتفسير، لا تصنيف بنموذج تعلم.
