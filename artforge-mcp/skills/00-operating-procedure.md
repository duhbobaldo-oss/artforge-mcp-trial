# مهارة 00 — إجراء التشغيل الإلزامي (Design Intent · Drawing Operations · Performance · Delivery)

## الغرض
أقصر مسار صحيح من طلب المستخدم إلى صورة مُسلَّمة ومُتحقق منها، مع معرفة أي مهارة وأي مرجع يُقرأ ومتى، دون عشرات الاستدعاءات ودون استبدال الطلب بتصميم عام.

## متى تُستخدم
مع **كل** طلب عبر ArtForge، وقبل أي مهارة أخرى.

## الأدوات (11)
| الأداة | متى |
|---|---|
| `artforge_create_design` | **الافتراضي لكل تصميم جديد**: فهم + تخطيط + مراجع + رسم + حفظ + تصدير + فحص + معاينة في استدعاء واحد |
| `artforge_plan_design` ثم `artforge_execute_design` | فقط لعرض الخطة قبل الرسم؛ مرّر `planId` **و** `requestId` من رد التخطيط نفسه |
| `artforge_tool_op` | كل تعديل بعد الإنشاء، دائمًا `op:"batch"` (المهارة 24). يرجع المعاينة المحدثة |
| `artforge_export` | صيغة أو مقاس آخر: png، jpeg، webp، svg، pdf، psd، bundle (المهارة 06) |
| `artforge_tool_docs` | `route` (المهارات التي تحتاجها المهمة)، `guide` (قراءة مهارة)، `query` (معاملات عملية) |
| `artforge_get_reference` | لوحات الألوان وأدلة التصميم وملفات الكتب (عند حاجة محددة) |
| `artforge_book_knowledge` | البحث في الكتب التسعة وقراءة صفحة (عند حاجة محددة) |
| `artforge_capabilities` / `artforge_status` | الأنواع والميزات والبناء الذي يجيب / صحة الخادم |
| `artforge_artifacts` | الملفات المصدّرة المحفوظة مؤقتًا (list/get/delete) |

## خريطة المهارات والمراجع
قبل تأليف بطاقة أو إعلان أو بوستر أو بنر أو شعار أو مجلة أو درس أو إنفوجرافيك أو معالجة مزج متجهة، اطلب `artforge_tool_docs {route:"<كلمات المستخدم>"}`. يرجع حتى 5 مهارات مرتبة ضمن ميزانية سياق. طبّق نصوص `briefs` المختارة، واقرأ الأدلة الأخرى ذات الصلة بـ `guide:"<id>"`. `guide:"list"` يعرض العقود والمصدر والبصمة والقواعد المقتبسة.

| المجموعة | المهارات | تُقرأ عندما |
|---|---|---|
| أساسية | `arabic-typography`، `tables`، `color-light-shadow`، `references`، `quality-delivery`، `model-drawing` | نص عربي، جدول، ألوان وإضاءة، استخدام المراجع، التسليم والتصدير، sceneSpec يدوي |
| أدوات محرك الرسم | `drawing` (متجهات)، `layers-and-effects`، `pixels-and-retouch`، `editing-workflow` | رسم يدوي، مؤثرات/أقنعة/ضبط/فلاتر، رتوش وتشويه، أي تعديل بعد الإنشاء |
| فنون عامة | `composition`، `value-and-form`، `figure-and-gesture`، `depth-and-space`، `materials-and-texture`، `nature-elements`، `mood-and-style` | قرار فني في رسم يدوي أو مراجعة؛ كل قاعدة فيها مقتبسة من كتاب وصفحة |
| المحرك الداخلي | `request-understanding`، `scene-graph`، `skill-routing`، `visual-references`، `art-direction`، `scenespec-engine`، `visual-review` | لفهم ما فعله المحرك وقراءة `direction.*` وتصحيحه |
| التكوين المتخصص | `promotional-layouts`، `logo-identity`، `editorial-layouts`، `educational-layouts`، `vector-colour-blending`، `ornamental-composition` | اختيار تخطيط ومقاييس حسب الاستخدام، وتنفيذ المزج أو التدرج بالطريقة التي يدعمها المحرك، وبناء الزخرفة (زهرة/عنقاء) بمسار عين ودراسة قيمة قبل اللون |

اختر بديلًا مناسبًا للهدف والقناة والنص. في سلسلة متكررة، ثبّت هوية القالب بالقدر الذي طلبه المستخدم. سجّل قرار المرجع وما غيّره في الرسم. للكتب واللوحات الداخلية المختارة استخدم `referenceApplications` مع معرّف معتمد وفهارس العمليات الفعلية. للمصدر الخارجي وثّق الرابط والملاحظة وقرار التنفيذ في التسليم، لأن حقل الربط الداخلي لا يقبل عنوان ويب.

**المراجع** (تُطبَّق آليًا داخل `create_design`، ولا تستدعِها قبله): 74 لوحة ألوان، 21 دليل تصميم، 9 كتب فنية (2004 صفحة)، و25 قاعدة فنية مقتبسة من صفحاتها ومربوطة بالمهارات. الدليل على تطبيقها في الرد: `evidence.applied[]` (المهارة 05).

## التعليمات الإلزامية
0. **السرعة = عدد الاستدعاءات.** كل استدعاء عبر ChatGPT نحو 4 ثوانٍ بينما عمل الخادم نحو 10ms. تصميم كامل = استدعاء واحد `create_design`؛ التخطيط المخصص (إنفوجرافيك، بطاقات، مخطط) = `sceneSpec` كامل في الاستدعاء نفسه. كل التعديلات = استدعاء `artforge_tool_op` واحد بـ `op:"batch"` (حتى 2000 عملية)، والرد يحمل المعاينة. لا ترسم شكلًا في كل استدعاء أبدًا.
1. **مرّر كلمات المستخدم حرفيًا** في `prompt` (الألوان والملابس والعلاقات والأعداد والنفي تُستخرج منها). الأنواع الأحد عشر: `text, poster, table, ruled, scene, character, landscape, architecture, abstract, card, reference`. إذا كان النوع واضحًا ولم يُكتشف، مرّر `designType`، والعناصر في `elements`.
2. **المقاس**: `width`/`height` كما ذكرهما المستخدم (ويُلتقط `1080x1350` من النص). لا تستبدلهما.
3. **النصوص حرفية**: `headline`/`body`/`kicker` كما كتبها المستخدم. النص الزائد يُرفض (`TEXT_TOO_LONG`) ولا يُقص سرًا. «بدون كتابة» = لا تمرّر نصوصًا.
4. **البيانات المنظمة**: الجداول في `table`، والنص الطويل في `blocks` أو `body` (`# عنوان`، `1- بند`، `- نقطة`)، والورق المسطر في `ruled`. لا ترسم الخلايا والأسطر يدويًا.
5. **المشهد غير المدعوم**: اقرأ `guide="model-drawing"` ومرّر `sceneSpec`، ولا تبدله ببطاقة نصية.
6. **اقرأ الرد قبل إعلان النجاح**: `verification.ok` و`verification.issues` و`warnings` (أي `QA…`) و`design.missing` و`design.limits`، وأبلغ المستخدم بها صراحة.
7. كل طلب جديد = استدعاء جديد؛ لا `planId:"latest"` ولا خطة طلب سابق.

## ترتيب العمل المختصر
```
create_design(prompt حرفي, نصوص حرفية, width/height, table|blocks|ruled|elements|sceneSpec عند الحاجة)
  → افحص verification + warnings + design.missing/limits، وانظر إلى الصورة
  → اعرض الصورة واذكر exported.path (وpages عند تعدد الصفحات)
  → تعديل؟ tool_op batch واحد (layer.list/object.list أولًا) ← المعاينة في الرد نفسه
  → صيغة أخرى (SVG/PDF/PSD) أو مقاس أكبر فقط عند الطلب ← artforge_export
```

## أخطاء شائعة (من جلسات حقيقية)
- **`skillId` لطلب رسم**: قالب نصي فقط (ملصق، بطاقة)؛ يتجاهله المحرك في الرسم ويذكر ذلك في `design.notices`.
- **البحث في الكتب أو المراجع قبل الرسم**: `create_design` يطبقها بنفسه ويذكرها في `evidence`.
- **تلخيص الطلب أو إعادة صياغته**: يحذف العلاقات والصفات.
- **إعادة الإنشاء لتعديل صغير**: تُفقد التعديلات؛ استخدم الدفعة.
- **تصدير بعد كل دفعة**: المعاينة في رد الدفعة.
- إعلان نجاح بمجرد وجود PNG دون قراءة `verification`.

## قبول الناتج
`executionOk` = نُفذت العمليات. `verification.ok` = الفحوص البنيوية (المقاس، النصوص، العناصر، الأعداد، العلاقات، الظهور بالبكسلات). `acceptance.visual = not-reviewed` = الجودة الفنية لم تُعتمد بصريًا. لا تعلن جودة احترافية من ملف PNG أو وسم عنصر فقط.

## حدود المحرك
رسم ثنائي الأبعاد (Skia): متجهات، تدرجات، فرش إجرائية، طبقات بكسل، مؤثرات وأقنعة وضبط وفلاتر غير إتلافية، تصدير SVG/PDF/PSD مع ICC. لا صور فوتوغرافية توليدية، ولا نقل أسلوب، ولا تشريح تفصيلي للوجوه والأيدي.
